# Open Mesa MVP

Aplicativo Expo/React Native para gestão de fichas e operações do caixa.

## Estrutura principal

- `src/` — código da aplicação (navegação, contextos, telas e componentes)
- `assets/` — arquivos visuais usados pelo Expo (`icon`, `favicon` e ícones Android)
- `openmesa-assets/` — pacote de identidade visual e tema do projeto
- `app.json` — configuração do Expo

## Como executar

```bash
npm install
npm start
```

Em seguida, escolha o alvo desejado no menu do Expo (`android`, `ios` ou `web`).
